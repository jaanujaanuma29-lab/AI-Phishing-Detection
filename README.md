\# 🛡️ PhishGuard AI



\### AI-Based Phishing Detection \& Cyber Threat Analysis System



PhishGuard AI is a machine learning-based cybersecurity application that analyzes URLs and identifies whether they are potentially \*\*phishing\*\* or \*\*legitimate\*\*.



The system extracts security-related features from a URL, processes them through a trained machine learning model, and provides a prediction along with a \*\*risk score\*\* and \*\*risk level\*\* through a web-based Flask application.



\---



\## 🚀 Features



\- 🔍 URL-based phishing detection

\- 🤖 Machine learning classification

\- 🧩 Automated URL feature extraction

\- 📊 Threat risk score

\- ⚠️ Risk level classification

\- 🌐 Interactive Flask web interface

\- 💻 Command-line URL prediction

\- 📁 Dataset validation and duplicate checking

\- 📈 Model evaluation using standard classification metrics
